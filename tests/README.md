# Проверки карты

`node tests/map-checks.js` — проверки страницы `/map` в Chromium (Playwright): 44 проверки, около 2 минут.

- Тест сам поднимает статический сервер для `public/` на свободном порту. Данные `data/` и настоящий API не нужны.
- Все внешние сервисы подменены. Overpass отвечает так, как задаёт тест: данные, пусто, ошибка или «зависание». Маршрут OSRM отдаётся с шагами или без них.
- POST-запросы на свой сервер блокируются, и число вызовов должно остаться нулевым. Геопозиция, микрофон и системное окно «Поделиться» подменены счётчиками, которые тоже должны остаться нулевыми.
- Что проверяется:
  - координаты в формах жалобы, обращения и просьбы о помощи;
  - формат даты ДД.ММ.ГГГГ;
  - конечные состояния быстрого поиска: результаты, «ничего не нашли», ошибка с «Повторить», «Отмена», тайм-аут;
  - каждый переключатель слоёв;
  - клавиатура в меню слоёв;
  - «Шаги» маршрута, источник данных рядом с оценкой, маршрут над нижней панелью;
  - раскладка на 320, 375, 620 и 1024 px;
  - первый запуск;
  - «Мои места»;
  - окно «Поделиться поездкой».
- Leaflet берётся с unpkg. Если сети нет, укажите в `LEAFLET_DIR` папку `node_modules` с пакетом `leaflet`.

Реальные данные и API этими проверками не покрыты: полноту OpenStreetMap, ответы Overpass, OSRM и Valhalla, геокодер, вход Supabase и push. Их проверяют вручную на https://inclusivecity.uk/map.
