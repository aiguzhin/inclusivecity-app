# ICity (inclusivecity-app)

Карта доступности для городов Казахстана: пешие маршруты с проверкой барьеров,
общественный транспорт, такси, жалобы на барьеры.

- Прод: https://inclusivecity.uk/ (домен на Cloudflare Registrar, DNS там же: CNAME `@` и `www` → `inclusivecity.onrender.com`, режим «DNS only»).
  Хостинг — Render, бесплатный план, Blueprint из `render.yaml`, деплой автоматически из `main`;
  адрес https://inclusivecity.onrender.com/ тоже работает.
  Railway (inclusivecity-production.up.railway.app) остановлен: закончился пробный период.
- Репозиторий приватный (с 14.10.2026): у GitHub Actions лимит 2000 минут в месяц.
- Supabase (бесплатный план) ставит проект на паузу после 7 дней без запросов: сервер каждый час дёргает `/storage/v1/bucket`, `/rest/v1/` и `/auth/v1/health`
  с анонимным ключом (результат — `supabase` в `/api/health`). Если всё же на паузе — Supabase Dashboard → проект ICity → Resume project.
- Не засыпать: сервер сам раз в 10 минут заходит на `RENDER_EXTERNAL_URL/api/health`; `.github/workflows/keepalive.yml` — раз в час
  (запасной будильник и письмо, если сайт не отвечает).
- Репозиторий: https://github.com/aiguzhin/inclusivecity-app
- Отображаемое название — «ICity»; домен и имя репозитория остаются `inclusivecity`.

## Устройство

- `server.js` — Node 18 без npm-зависимостей: статика из `public/`, API жалоб,
  `/bus-<город>.json` (маршруты транспорта из OpenStreetMap, кэш в `data/bus/`,
  обновление раз в неделю), `/api/taxi-tariffs`, `/api/taxi-price`
  (живая цена Яндекс Go — только при `YANDEX_TAXI_CLID` и `YANDEX_TAXI_APIKEY`).
- `public/landing.html` — главная `/`: 3D-лендинг (three.js r128 с cdnjs), полёт камеры по скроллу.
- `public/index.html` — всё приложение (Leaflet, тексты на ru/kk/en в `I18N`), открывается на `/map`
  (и по старому адресу `/index.html`); PWA стартует с `/map`.
- `public/login.html` — `/login` и `/account`: вход и регистрация через Supabase Auth
  (supabase-js 2.45.4 UMD с jsDelivr, PKCE). Регистрация по телефону с кодом из SMS или по почте, вход по телефону/почте
  с паролем, восстановление пароля по SMS или письму, Google; Apple и eGov — кнопки «скоро». Номера — только +7 (10 цифр).
  Ключи отдаёт сервер в `/auth-config.js` из переменных окружения `SUPABASE_URL` и `SUPABASE_ANON_KEY`
  (без них страница показывает «Вход скоро заработает»). Кнопка «Войти/Профиль» в приложении и на лендинге
  смотрит сессию в localStorage (`sb-…-auth-token`).
- `assistant.js` — `/api/assistant`: ИИ-помощник «Серік» (гид по доступному городу + бережная поддержка),
  прокси к Anthropic API; ключ `ANTHROPIC_API_KEY` в переменных Render (без него чат пишет «не подключён»),
  модель — `ASSISTANT_MODEL` (по умолчанию `claude-haiku-5-5`), лимит 40 сообщений в час с IP.
- `placeinfo.js` — `/api/place-info` и `/api/place-photo`: фото, рейтинг и отзывы заведений в карточке места
  (Google Places API (New), ключ `GOOGLE_PLACES_KEY`, кэш на неделю); без ключа — фото Wikimedia Commons по тегам OSM.
  Ссылку на 2ГИС в карточке места убрали. Телефоны приводятся к виду `+7 XXX XXX XX XX` (`kzPhone`).
- Контакты заведений: `tools/overture_places.py` (DuckDB, Overture Maps places) по workflow `places.yml` пишет
  `public/places/<город>.json`; `placeEnrichContacts` в `index.html` подставляет телефон/сайт/Instagram, если их нет в OSM.
- Такси своего города: в `buildTaxiTrip` блок `cityTaxiHtml(город)` — только службы города, откуда едем:
  `YA_PHONE` (Яндекс Go по телефону), `public/taxi-osm.json` (службы такси из OSM, `tools/osm_taxi.py` по workflow `taxi.yml`)
  и `INVATAXI` (номера инватакси: 2ГИС и источники 2024–2026; `old:1` — только старый справочник Saby, помечается).
  С 20.09.2026 право на инватакси — по единому перечню 18 показаний (приказ Минздрава №102), заявка — акимат или Портал соцуслуг.
- Заставка `#icIntro` (сразу после `<body>` в `index.html`): холст 2D, ~3 с — сеть 22 городов → полёт к своему городу (`ic_city`) → знак ICity;
  касание/клавиша — пропустить, `ic_motion=off` или reduced-motion — короткий показ; сама снижает разрешение, если кадры опаздывают.
- Сохраняется между входами (localStorage `ic_*`): язык, город, тема, шрифт, контраст, профиль, способ, подложка, вид,
  положение карты (`ic_mapPos`, только для того же города) и включённые слои (`ic_layers`).
- Мои места (`PLACES`, `ic_places`): дом, работа, места и маршруты под полем «Куда»; последние «Откуда/Куда» — `ic_f_start/destination`.
  Дом/работа: окно `#psModal` (`openPlaceSet`, адрес с подсказками или ⌖) → значки на карте (`drawHomePins`, домик и портфель); карточка в шторке — `showHomePlace` (просто показать), нажатие на значок — карточка места с «Маршрут сюда».
- Погода на маршруте: `tripWeather`/`effSlope` — в гололёд допустимый уклон ×0.6, прогноз Open-Meteo по часам на время пути.
- Навигатор: голос за ~150 м (если до поворота далеко), за ~50 м и «Сейчас…» на повороте (`navAction`, `spokenDist`, `speechify`), стрелка «я» (`.nav-me`), пройденное — серым (`navProgress`);
  «Озвучить маршрут» — короткая сводка; голос — лучший из системных (`pickVoice` по качеству). Виды мест — `PLACE_KIND` (без английских слов в ru/kk), часы — `ohHuman`.
- Спутник чётче: `.sat-crisp` (контраст/насыщенность), «эскиз» прячется после загрузки; в 3D — raster-contrast/saturation, pixelRatio 2.
  Прогулка в 3D как в Google Earth: держите ↑/↓/↺/↻ или стрелки/WASD (Shift — бег, кнопка «»»), ведите по экрану — осмотреться (`walkLoop`, `walkLook`).
- Карточка места: сверху крупные кнопки Маршрут · Позвонить · Сохранить · Поделиться (`.pc-bar`, `placeSave`, `placeShare` → `/map?at=lat,lon&n=`).
  Фото: Google (если ключ) + фото из отзывов + Wikimedia Commons в радиусе 120 м + Panoramax (до 12); подписей об источниках в карточке нет, автор — только в просмотре.
  Нажатие на улицу → данные улицы из OSM (`streetFacts`: тип, покрытие, тротуары, освещение, скорость, полосы, ровность, уклон) и уличные снимки.
- Отзывы: 5 крупных звёзд с подписью, плитки фото как в 2ГИС (до 5, `rvTiles`), сервер принимает несколько `photo`, хранит `photos[]` + KV;
  отзывы ищутся по месту или в 30 м с тем же названием (osm-id мог появиться позже); свои — `ic_myReviews`.
- Заставка ~1,2 с; пружинные анимации (`--spring`); на телефоне +/− скрыты, включаются в настройках (`ic_zoomBtns`).
- Маршрут готов → в шторке кнопки «Поехали» / «Шаги» / ✕ (`#peekRoute`, `clearRouteAll`). Навигация: сверху манёвр крупно (`#navHud`), снизу время, км, «прибытие в» и кнопки (`#navBar`);
  камера `navCamera` — зум 18, человек в нижней части, карта по курсу GPS/компасу; «Весь маршрут» (`navOverview`) на 12 с.
- Поиск только в своём городе: Nominatim `bounded=1` + Photon (komoot) с bbox города, `inCity`; иначе «В городе … ничего не нашли». Выбранные «Откуда/Куда» — значки `drawFieldPin` сразу.
- Векторный слой не «уплывает»: `glPatch(gl)` в `addGLLayer` заменяет синхронизацию плагина maplibre-gl-leaflet — квадратный холст с запасом по диагонали,
  по центру карты в координатах поворотной панели, перецентровка только за пределами запаса и в конце движения, `redraw()` синхронно; щипок/поворот/анимации учтены.
- Подписи и заведения векторной карты — в pane `labels` внутри `map._rotatePane` (z 250): иначе leaflet-rotate прячет их под снимком.
- Текстовый режим (`ic_view=list`) на телефоне закрывает карту целиком (`#listview` z 600) и даёт кнопку «Вернуться к карте».
- Навигация `navStart` (объект `NAV`): watchPosition, голос `navSay` (говорит всегда), вибрация, барьеры впереди, перестроение после 3 точек >40 м, Wake Lock.
- Офлайн: «Скачать город» (`offlineDownload`) — слои в Cache API `ic-offline`, тайлы z10–13 в `ic-tiles`; оба кэша не стираются при смене `ic-vN`.
- Рейтинг районов `openRating`: place=suburb/quarter из OSM, удобства/барьеры/жалобы → 0–100, теплокарта 600 м, кэш 7 дней.
- `rating.js`: `/api/rating?city=&bb=` — рейтинг районов считает сервер (один запрос Overpass с `make sep`, до 2 мин), кэш 7 дней в памяти + KV `rating:<city>`;
  пока считает — 202, клиент (`rtCompute`) через ~8 с параллельно спрашивает Overpass сам. `overpassQuery` спрашивает два зеркала сразу.
- Высоты для уклонов: сначала Open-Meteo elevation, потом opentopodata/open-elevation (`fetchElevations`).
- Пустое «Откуда» при построении маршрута → берём GPS, иначе просим указать (`needStart`). Место из поиска/категорий отмечается `placePin` в `showPlace`.
- Геопозиция не даётся → окно `geoHelp` с шагами под платформу (`geoPlatform`: iOS Safari, macOS Safari, Android, ПК, встроенный браузер Claude — там геопозиции нет совсем)
  и кнопка «Отметить моё место на карте» (`geoManual`, `pickMode="me"`, хранится в sessionStorage `ic_manualLoc`).
- Серік без ключа отвечает на частые вопросы сам (`SK_FAQ`, `serikLocal`).
- `/login`, `/account`: кнопка «Назад» (`#backBtn`, назад по истории или на `/map`); без входа на `/account` — заголовок «Ваш профиль» и объяснение.
- Шторка без заголовка (только ручка и ✕). ✕ срабатывает по координатам касания (`sheetClose`, захват pointerdown/up на document) и гасит «досланный» click;
  нажатие на карту над полуоткрытой шторкой закрывает её, следующее — убирает оставшуюся точку места (`placePin`).
- Нижнее меню: «Карта» — `navMapTab` (сворачивает шторку), «Мои места» — `navPlacesTab`.
- Спутник: «эскиз» (`basePreview`) всегда под чёткими плитками; `SatLayer` при ошибке картинки берёт уровень крупнее; контуров домов поверх снимка нет.
- `social.js`: `/api/reviews` (отзывы с галочками и фото), `/api/help` (просьбы волонтёрам, точное место — после отклика), статусы жалоб
  `/api/reports/:id/status`; в админке — «В работе»/«Исправлено». Данные в `data/reviews.json`, `data/help.json` + копия в Cloudflare KV
  (без CF_* переменных стираются при деплое; `/api/health` показывает `storage`).
- Стиль «Мягкий минимализм» — по умолчанию (`html[data-ui="soft"]`, `ic_ui`, Настройки → Стиль оформления, «Классический» — прежний вид):
  в плашке приветствие `renderHello`, карточки Дом/Работа `renderPeekPlaces`, 4 плитки и тёмное меню-«таблетка» (Карта, Мои места, Серік, Профиль).
- Шторка-плашка: по умолчанию свёрнута (`.sheet-peek.mini`: поиск + меню), свайп вверх/кнопка «⌃» раскрывают приветствие, Дом/Работа и плитки (`peekExpand`, `ic_peekFull`).
- Кнопка «три линии» на карте (`#mapMenuBtn`, `toggleMapMenu`): внутри слои (`#layerbar`), погода (`#wx`) и подпись снимка (`#imgInfo`) — перенесены туда при запуске (`initMapMenu`); значок — число включённых слоёв.
- Поиск в шторке (как в 2ГИС): «Куда едем?» → `openPeekSearch` (`.sheet-peek.finding`): поле `#pq` с подсказками и 8 категорий `PF_CATS`
  (аптеки, поесть, продукты, банкоматы, больницы, остановки, ТЦ, парки) — Overpass в радиусе 1,6 км → значки `pfLayer` и карточки `#peekRes`;
  выбор → шторка опускается, `showPlace`. Карточка места на телефоне — снизу вместо шторки, место — в видимой части карты.
- Плитки шторки: Помощь (волонтёры), Туалет, Барьер, SOS; «Серік» в шапке на телефоне скрыт (есть в нижнем меню); автоподсказка про 3D выключена.
- Кнопки внизу: Я здесь, Туалет (`nearestToilet`), Барьер, SOS, Ещё; «Поделиться поездкой» (`shareTrip`); ярлыки PWA `/map?do=home|toilet|help|sos`.
- Профиль `/account` (`login.html`): фото (обрезка 320×320 → `POST /api/avatar`, `profile.js` проверяет токен Supabase, файл в `data/avatars` + KV `avatar:<id>`),
  имя/почта/телефон (смена номера — SMS-код `phone_change`)/пароль, профиль передвижения, «Мои места», переключатель уведомлений.
  Свои имя и фото — в `user_metadata.ic_name`/`ic_avatar` (Google при входе перезаписывает `full_name`/`avatar_url`); `ic_avatar:""` — фото убрано.
- `/login` и `/account` — светлая/тёмная тема и крупный шрифт (кнопки в шапке, те же `ic_theme`/`ic_font`/`ic_contrast`, что в приложении);
  фото перед загрузкой настраивается в окне `#crop` (сдвиг, масштаб, поворот); пароль, заданный Google-пользователем, помечается `ic_has_pw`;
  без SMS в Supabase номер сохраняется без кода в `ic_phone`; близкий человек для SOS — `ic_sos` + `ic_sosContact` → в окне SOS кнопки «Позвонить»/«SMS» (`renderSosMine`).
- Регистрация: кнопка «Регистрация» (`/login#signup`) рядом с «Войти» на главной (`#signupTop`), в шапке карты (`#signupBtn`) и в меню (`#mmSignup`); после входа скрыта.
  «О себе» (`renderAbout`, `AB`): возраст группой (`ic_age`: none/u18/18/40/60/75) и особенности (`ic_needs`) при регистрации и в профиле (`#aboutAcc`, подсказка `#aboutNudge` для Google-входа);
  `abPlan` → 60+ крупный шрифт, 75+ очень крупный и без анимаций, «не вижу/плохо вижу» — очень крупный + контраст (+ голос для незрячих), профиль маршрута — `mobility`.
- Мои места синхронизируются с аккаунтом: `user_metadata.places` + `places_at`, побеждает более свежая копия (`cloudSavePlaces`/`cloudLoadPlaces`, `ic_placesAt`).
- Push-уведомления (`push.js`, без зависимостей: VAPID ES256 + aes128gcm): ключи VAPID — из `VAPID_PUBLIC_KEY`/`VAPID_PRIVATE_KEY` или создаются и хранятся в KV `vapid`;
  подписки (`/api/push/subscribe`, только адреса push-сервисов браузеров) следят за своими жалобами и просьбой о помощи — `pushSync` в `index.html`;
  уведомляют смена статуса жалобы в админке и отклик волонтёра; `sw.js` показывает push и открывает `url` (`/map?do=reports|help`).
- Заведения на векторной карте (`morePoi`): иконки магазинов/кафе/аптек — на 2 зума раньше, чем в стиле liberty, подпись необязательна.
- Профиль передвижения — в настройках (`#secProfile`), пункт «Профиль: …» в меню «три линии» (`#mmProf`) и на `/account`; строка `.prof-chip` в «Куда едем?» скрыта.
- Погода — снова на карте справа вверху (`#wx` не переносится в панель ≡).
- Спутник — слой `SatLayer`: перед плиткой спрашивает tilemap Esri (блоками 8×8), где снимка нет — растягивает ближайший более крупный уровень, поэтому заглушек «Map data not yet available» нет (maxNativeZoom 19).
  Подпись «Снимок: дата» убрана. Год снимков — Настройки → «Год спутниковых снимков» (`setSatYear`, `ic_satYear`): выпуск Wayback до конца года, выпуск каждой плитки — из tilemap `select`.
- Глобус (`openGlobe` в `index.html`): при зуме ≤ 3 вместо карты — Земля на three.js: реальные день/ночь по времени,
  облака, звёзды (рисуются, без картинки), Солнце и Луна (`globeAstro`). Без подсказки и без точек городов; ждём только карту Земли 2048 px (остальное догружается),
  при зуме ≤ 6 — фоновая предзагрузка (`globePrefetch`). Кнопки: капсулы ☀/☾ и +/− справа, «К карте» (`.gl-back`) внизу по центру.
- Поворот карты ВЫКЛЮЧЕН (`MAP_ROTATE=false`, `canRotate()`): на телефоне карта случайно поворачивалась и слои расходились; компас скрыт, в навигации крутится стрелка.
  Раньше: leaflet-rotate 0.2.8 (unpkg, SRI): два пальца/Shift+мышь. Компас `#compassBtn` (`compassTap`, `compassMode` north/follow):
  нажатие — карта по направлению телефона (`map.setBearing(-heading)`, синяя кнопка), ещё раз или после ручного поворота — север вверху (`setNorthUp`); стрелка всегда на север.
- 3D — только жестом (два пальца вверх, правая кнопка мыши); обычная карта прячется лишь когда 3D дорисовалась (`is3d-ready`).
- Голосовые подсказки для незрячих (`S.hints` в `index.html`): первое касание называет элемент, второе нажимает.
- Защита: заголовки безопасности (`securityHeaders`: HSTS, запрет показа в чужой рамке, nosniff и др.), API только со своих адресов (`OWN_HOSTS`, `foreignOrigin` → 403)
  и лимиты по IP (`tooMany`: 600/мин, платные запросы — 60/мин); `ADMIN_TOKEN` без переменной — случайный (в логах), 10 ошибок за 15 мин с IP — блок;
  на чужом домене страницы показывают «неофициальная копия» и уводят на inclusivecity.uk; `LICENSE` — все права защищены; `robots.txt` закрывает ИИ-сборщики.
- Всегда открывается: `sw.js` отдаёт сохранённую страницу, если сервер молчит > 3,5 с (Render просыпается) или отвечает 5xx, а свежую кладёт в кэш;
  без кэша и без сети — страница «ICity загружается…» с автообновлением. SW регистрируют `/map`, `/` и `/login`.
  В `server.js` — `uncaughtException`/`unhandledRejection` только в лог, `keepAliveTimeout` 65 с. GitHub cron на деле срабатывает раз в несколько часов.
- `public/sw.js` — офлайн-кэш; при каждом изменении фронтенда поднимать `CACHE` (`ic-vN`).
- `data/` на бесплатном Render не сохраняется между деплоями (нет диска) — кэши пересобираются,
  жалобы и фото пропадают; для постоянного хранения нужен платный план с диском (см. `render.yaml`).

## Как работать

- Навыки в `.claude/skills`: `find-skills` (vercel-labs, поиск навыков; CLI `npx skills find` отсюда не достаёт API — смотреть skills.sh через WebFetch),
  `web-design-guidelines` (vercel-labs; правила — github.com/vercel-labs/web-interface-guidelines `command.md`), `ui-ux-pro-max`.
- Фирменный цвет — синий (#1769c2 светлая / #2563eb тёмная) на главной, входе и карте; зелёный — только смысл «доступно».
  Высокий контраст (`ic_contrast=high`) — чёрный/белый + жёлтые кнопки #ffd400 на всех страницах; на главной и входе кнопки «Аа», ◐ и тема
  (на главной на телефоне — в меню `#vMenuBtn`); главная в светлой теме — дневной 3D-город (`sceneTheme`, событие `ic-theme`).
- Навык дизайна UI/UX Pro Max (MIT, github.com/nextlevelbuilder/ui-ux-pro-max-skill) — в `.claude/skills/ui-ux-pro-max`:
  перед правками интерфейса — `python3 .claude/skills/ui-ux-pro-max/scripts/search.py "<запрос>" --design-system` или `--domain ux|color|typography`.

- На этом Mac нет Node.js и git. Проверка синтаксиса сервера:
  `/System/Library/Frameworks/JavaScriptCore.framework/Versions/Current/Helpers/jsc -e 'checkSyntax("server.js")'`.
- Фронтенд локально: `ruby -run -e httpd public -p 8765` (API там нет).
- Изменения загружаются на GitHub: из облачной сессии — git push в main (репозиторий подключён),
  иначе через веб-интерфейс (Upload files), сразу после проверки; после деплоя — проверить сайт и дать ссылку.
- Цены такси — оценка по официальному тарифу «Эконом» Яндекс Go; таблица
  `TAXI_TARIFFS` в `index.html` снята с taxi.yandex.kz 05.10.2026.
